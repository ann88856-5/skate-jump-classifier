# Нейросетевая платформа для видеоанализа и судейства в фигурном катании

Проект представляет собой веб-приложение для автоматического анализа прыжков в фигурном катании. Система принимает видео, определяет тип прыжка с помощью нейросети BiLSTM, подсчитывает количество оборотов, сохраняет результат в базу данных и отображает скелет фигуриста прямо на видео.

## Стек технологий
*   **Backend:** Python 3.14, FastAPI, PyTorch, OpenCV, MediaPipe, psycopg (v3)
*   **Frontend:** React, Vite, TypeScript
*   **База данных:** PostgreSQL
*   **Дополнительно:** FFmpeg (для конвертации видео), ReportLab (для PDF)

---

## Инструкция по запуску

### 1. Предварительные требования
Перед запуском убедитесь, что у вас установлены:
*   **Python 3.11+** (рекомендуется 3.11 или 3.12)
*   **Node.js** (для фронтенда)
*   **PostgreSQL** (создайте базу данных `skate_analysis`)
*   **FFmpeg** (обязательно добавлен в системную переменную PATH)
*   **Git**

### 2. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_ЛОГИН/skate-jump-classifier.git
cd skate-jump-classifier
```

### 3. Настройка окружения (Python)
Установите все необходимые библиотеки для бэкенда:

```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных
Откройте терминал PostgreSQL или pgAdmin.

Создайте базу данных:
```sql
CREATE DATABASE skate_analysis;
Проверьте настройки подключения в app.py (блок DB_CONFIG). Убедитесь, что логин, пароль и порт совпадают с вашими.
```
### 5. Запуск Backend (Сервер)
Откройте первое окно терминала в корневой папке проекта и выполните:

```bash
uvicorn app:app --reload
```
Сервер запустится на http://127.0.0.1:8000. При первом запуске загрузится нейросетевая модель.

### 6. Запуск Frontend (Клиент)
Откройте второе окно терминала и перейдите в папку с фронтендом:

```bash
cd frontend
npm install
npm run dev
```
Клиент запустится на http://localhost:5173.

### 7. Использование
Откройте браузер и перейдите по адресу: http://localhost:5173

Нажмите «Выберите файл» и загрузите любое видео с прыжком (например, из папки videos/).

Нажмите «Анализировать».

Дождитесь результата: вы увидите тип прыжка, уверенность модели, количество оборотов и видео с наложенным скелетом.

### Структура проекта
app.py — основной файл бэкенда (FastAPI).

frontend/ — исходный код интерфейса (React).

dataset/ — данные, веса модели и загруженные видео.

train_lstm.py — скрипт обучения нейросети.

overlay_skeleton.py — скрипт для тестирования визуализации.

init_db.py — скрипт создания таблиц в базе данных.
